# 網路商店（前台購物網站＋管理後台，Firebase）

單一品牌的網路商店，功能參考 meepShop 後台。顧客在前台逛商品、加入購物車、結帳、查訂單；店家在後台管理訂單、商品、顧客、頁面設計和行銷活動。

| 網址 | 用途 |
|---|---|
| `/` | 前台：首頁、商品、購物車、結帳、會員中心 |
| `/admin` | 後台，用 Google 帳號登入 |
| `/api/shop`、`/api/admin` | Cloud Functions API |

## 本機試用

```bash
npm install
cd functions && npm install && cd ..
npm run dev        # 開 Firebase 模擬器（第一次會比較久）
npm run seed       # 另開一個終端機：填入示範商品、頁面、訂單（會清空模擬器裡的舊資料）
```

| | |
|---|---|
| 前台 | http://127.0.0.1:5160 |
| 後台 | http://127.0.0.1:5160/admin ：按「使用 Google 帳號登入」→ 在模擬器的彈窗按「Add new account」→ Email 填 `admin@example.com` |
| 示範會員 | `customer@example.com`／`123456` |
| 優惠碼 | `WELCOME100`（滿 1000 折 100，每人一次） |
| 特約代碼 | 註冊時填 `ganbaru` 會直接成為「甘爹 VIP」（全館九折） |
| 模擬器面板 | http://127.0.0.1:4100 （看資料庫、登入帳號） |

模擬器的連接埠刻意跟其他專案錯開（5160、9399、8180、9599、5101、4100），可以同時開。關掉模擬器時資料會存到 `.emulator-data/`，下次 `npm run dev` 會自動載入。

## 架構

| 部分 | 內容 |
|---|---|
| `public/index.html`、`store.js`、`store.css` | 前台（單頁應用） |
| `public/admin.html`、`public/admin/*.js` | 後台，每個功能一個檔案 |
| `public/shared/blocks.js` | 頁面區塊的顯示方式，前台和後台頁面編輯器共用 |
| `functions/api/shop.js`、`admin.js` | API |
| `functions/lib/pricing.js` | 價格計算：會員折扣、湊湊團、加購、滿額折、優惠碼、免運、購物金，前台試算和結帳共用 |
| `functions/lib/orders.js` | 下單（交易內扣庫存）、改狀態、取消（加回庫存、退購物金）、會員等級升級 |
| Firestore | 瀏覽器不能直接讀寫，全部經過 Cloud Functions（各集合說明在 `functions/lib/db.js` 開頭） |
| Storage | 媒體櫃圖片（上傳時自動縮圖、轉 WebP） |

## 功能

**前台**：首頁和自訂分頁（後台拖拉設計）、商品列表（標籤、搜尋、排序）、商品頁（多規格、庫存、收藏、商品問答、湊湊團進度）、購物車（加價購、優惠碼、免運提示）、結帳（訪客或會員、運送方式、付款方式、購物金折抵）、訂單頁（模擬付款、轉帳通知、取消、退換貨申請、訂單問答）、會員中心（等級、購物金紀錄、訂單、收藏、問答、資料）、全站公告、彈窗廣告。

**後台**

| 選單 | 內容 |
|---|---|
| 總覽 | 本月營收、毛利、30 天營收圖、待辦事項、熱銷、庫存不足 |
| 訂單 | 分頁籤（處理中／備貨中／已出貨／退換貨／結案或取消）、搜尋、日期、批次改狀態、匯出 CSV、上傳物流編號、訂單詳情（改狀態、訂單問答、處理紀錄、列印出貨單） |
| 商品 | 上下架、標籤、規格組合（最多 3 種）、各規格價格與庫存、圖片排序、商品介紹編輯器、批次操作、匯出 |
| 訊息中心 | 訂單問答（未讀、標記）、商品問答（未回覆） |
| 顧客管理 | 顧客名單（篩選、匯入／匯出、贈送購物金、黑名單）、顧客群組（自動升級／續會條件）、特約代碼、顧客分眾（RFM、消費行為，可下載名單） |
| 商店設計 | 頁面設計（拖拉元件：群組多欄、圖片、輪播、圖片文字、文字、倒數、商品列表、影片、臉書、分享、選單、地圖、間距；電腦／手機預覽、復原）、選單目錄（置頂、側邊、頁尾，三層）、全站外觀（配色、按鈕、動畫、版型、背景、公告、彈窗） |
| 行銷 | 折扣（商品折扣、滿額折、優惠碼、免運、購物金：滿額贈送／生日／入會）、試算、計算順序、購物車加購區、湊湊團 |
| 媒體櫃 | 拖拉上傳、資料夾、搜尋、改名、刪除 |
| 設定 | 商店、購物、顧客功能、金流、物流、第三方、通知、後台帳號（老闆／店長／客服／商品與設計） |

## 目前是模擬的部分

- **金流**：信用卡是「模擬付款成功／失敗」按鈕；ATM 轉帳顯示匯款帳號，讓顧客回填末五碼。綠界的金鑰欄位已經在「設定 → 金流管理」預留。
- **物流**：超商取貨讓顧客自己填門市；之後串綠界物流改成地圖選店、自動產生物流編號。
- **通知**：沒有寄 Email／LINE，只在後台顯示待辦數字。
- **每日排程**（轉帳逾期自動取消、生日購物金、會員等級到期）：在 `functions/index.js` 的 `daily`，模擬器裡不會跑，部署後才會每天凌晨 3 點執行。

## 上線

1. Firebase Console 建立專案，升級 Blaze 方案；開 Firestore（asia-east1）、Storage、Authentication（啟用 Google 與「電子郵件／密碼」）。
2. 把 `.firebaserc` 的 `demo-onlineshop` 改成你的專案 ID。
3. 建立 `functions/.env`，寫上 `OWNER_EMAILS=你的Gmail`（老闆帳號，可以用逗號分開多個）。
4. `npx firebase login`，然後 `npm run deploy`。
